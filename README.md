# Gym Buddies 💪

筋トレ記録アプリ - 友達と一緒にモチベーションを高めよう！

## 📋 概要

Gym Buddiesは、個人の筋トレ記録を手間なく記録し、友達の記録・進捗を相互に可視化してモチベーションを高めるWebアプリケーションです。

## ✨ 実装済み機能（MVP Phase 1）

### 認証
- ✅ メール + パスワードでの新規登録
- ✅ ログイン/ログアウト
- ✅ セッション管理（NextAuth.js）

### ワークアウト記録
- ✅ 当日のダッシュボード
  - 総種目数、総セット数、総レップ数、総負荷量（kg-reps）の4指標表示
  - 記録した種目の一覧表示
  - FAB（フローティングアクションボタン）で新規記録追加
- ✅ 種目選択
  - 部位別フィルタリング（ALL / 胸 / 腕 / 肩 / 背中 / 脚 / 腹筋）
  - 前回のワークアウト日時表示
  - 60種類以上の種目データ
- ✅ セット記録
  - 重量、回数、RPE（任意）の入力
  - セットの追加・削除・複製
  - 完了チェック機能
  - 前回記録の表示
  - カウントダウンタイマー（60秒）
  - 単位切替（kg ⇄ lbs）
  - メモ機能
  - 公開範囲設定（友達のみ / 非公開）
- ✅ PR（自己ベスト）検出
  - 重量PR
  - 体積PR（重量 × 回数）

### データモデル
- ✅ User（ユーザー）
- ✅ Exercise（種目マスタ）
- ✅ Workout（ワークアウト）
- ✅ Set（セット）
- ✅ Follow（フォロー関係）
- ✅ Like（いいね）

## 📦 セットアップ

### 前提条件

- Node.js 18.16.1以上
- PostgreSQL
- npm

### 1. リポジトリのクローン

```bash
git clone <repository-url>
cd Gym-Buddies
```

### 2. 依存関係のインストール

```bash
npm install --legacy-peer-deps
```

### 3. 環境変数の設定

`.env`ファイルを作成し、以下の内容を記入：

```env
DATABASE_URL="postgresql://user:password@localhost:5432/gymbuddies?schema=public"
NEXTAUTH_SECRET="your-secret-key-generate-with-openssl-rand-base64-32"
NEXTAUTH_URL="http://localhost:3000"
```

### 4. データベースのセットアップ

```bash
# Prismaスキーマをデータベースに反映
npm run db:push

# 種目データのシード
npm run db:seed
```

### 5. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## 🎯 使い方

### 1. アカウント作成

1. トップページで「新規登録」をクリック
2. 表示名、メールアドレス、パスワードを入力
3. 「登録」をクリック

### 2. ログイン

1. メールアドレスとパスワードを入力
2. 「ログイン」をクリック

### 3. ワークアウト記録

1. ダッシュボードの「+」ボタンをクリック
2. 部位を選択し、種目を選ぶ
3. セットごとに重量・回数を入力
4. 完了したセットにチェックを入れる
5. 「保存」をクリック

### 4. 単位変換

- ワークアウト記録画面の右上で kg ⇄ lbs を切り替え可能
- 内部的には常にkgで保存され、表示時に変換されます

## 🔒 セキュリティ

- パスワードは bcrypt でハッシュ化して保存
- セッション管理は JWT ベース
- 公開範囲設定により、非公開のワークアウトは本人のみ閲覧可能
- フォロワーのみが「友達のみ」設定のワークアウトを閲覧可能（実装予定）

## 📊 データベーススキーマ

詳細は `prisma/schema.prisma` を参照してください。

主要なテーブル：
- `users` - ユーザー情報
- `exercises` - 種目マスタ
- `workouts` - ワークアウト
- `sets` - セット記録
- `follows` - フォロー関係
- `likes` - いいね
