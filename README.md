# Gym Buddies 💪

筋トレ記録アプリ - 友達と一緒にモチベーションを高めよう！

## 📋 概要

Gym Buddiesは、個人の筋トレ記録を手間なく記録し、友達の記録・進捗を相互に可視化してモチベーションを高めるWebアプリケーションです。

## 📦 セットアップ

### 前提条件

- Node.js 18.16.1以上
- npm
- （オプション）PostgreSQL（本番環境用）

### 1. リポジトリのクローン

```bash
git clone <repository-url>
cd Gym-Buddies
```

### 2. 依存関係のインストール

```bash
npm install --legacy-peer-deps
```

### 3. 環境変数の設定

`.env`ファイルを作成し、以下の内容を記入：

**開発環境（SQLite使用）:**
```env
DATABASE_URL="file:./dev.db"
NEXTAUTH_SECRET="your-secret-key-generate-with-openssl-rand-base64-32"
NEXTAUTH_URL="http://localhost:3000"
```

**本番環境（PostgreSQL使用）:**
```env
DATABASE_URL="postgresql://user:password@localhost:5432/gymbuddies?schema=public"
NEXTAUTH_SECRET="your-secret-key-generate-with-openssl-rand-base64-32"
NEXTAUTH_URL="https://your-domain.com"
```

> 注: PostgreSQLを使う場合は、`prisma/schema.prisma`の`provider`を`"postgresql"`に変更してください。

### 4. データベースのセットアップ

```bash
# Prismaスキーマをデータベースに反映
npm run db:push

# 種目データのシード
npm run db:seed
```

### 5. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

## 🎯 使い方

### 1. アカウント作成

1. トップページで「新規登録」をクリック
2. 表示名、メールアドレス、パスワードを入力
3. 「登録」をクリック

### 2. ログイン

1. メールアドレスとパスワードを入力
2. 「ログイン」をクリック

### 3. ワークアウト記録

1. ダッシュボードの「+」ボタンをクリック
2. 部位を選択し、種目を選ぶ
3. セットごとに重量・回数を入力
4. 完了したセットにチェックを入れる
5. 「保存」をクリック

### 4. 単位変換

- ワークアウト記録画面の右上で kg ⇄ lbs を切り替え可能
- 内部的には常にkgで保存され、表示時に変換されます

## 🔒 セキュリティ

- パスワードは bcrypt でハッシュ化して保存
- セッション管理は JWT ベース
- 公開範囲設定により、非公開のワークアウトは本人のみ閲覧可能
- フォロワーのみが「友達のみ」設定のワークアウトを閲覧可能（実装予定）

## 🐛 既知の制限事項

- Node.js 18.16.1を使用（18.17.0未満）のため、一部の依存関係で警告が出ます（動作には問題ありません）
- ディレクトリ名に大文字が含まれるため、npm パッケージ名は小文字の`gym-buddies`としています
